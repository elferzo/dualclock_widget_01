# Dual Clock Widget — Астрахань / Когалым

Прозрачный виджет часов для Samsung Fold с двумя часовыми поясами:
- **Астрахань** — UTC+4
- **Когалым** — UTC+5

## Файлы в репозитории

| Файл | Назначение |
|------|------------|
| `DualClockWidget.kt` | Основной провайдер виджета |
| `ClockUpdateService.kt` | Сервис обновления каждую минуту |
| `BootReceiver.kt` | Автозапуск после перезагрузки |
| `widget_layout.xml` | Разметка виджета (прозрачный фон) |
| `widget_info.xml` | Параметры виджета |
| `strings.xml` | Строковые ресурсы |
| `AndroidManifest.xml` | Манифест приложения |
| `build.gradle` | Gradle конфигурация (app) |
| `settings.gradle` | Gradle настройки проекта |
| `setup_project.sh` | Скрипт сборки структуры папок |
| `build_apk.yml` | GitHub Actions — сборка APK |

## Как получить APK через GitHub Actions

### 1. Создайте репозиторий
Загрузите **все файлы** из этого архива в **корень** нового репозитория (без подпапок).

### 2. Добавьте GitHub Actions workflow
В репозитории создайте папку `.github/workflows/` и положите туда `build_apk.yml`.

Или используйте команду в Actions → создайте новый workflow и вставьте содержимое `build_apk.yml`.

### 3. Запустите сборку
- Перейдите в **Actions** → **Build APK** → **Run workflow**
- Через ~3 минуты появится APK в разделе **Releases** или **Artifacts**

### 4. Установите APK
- Скачайте APK на телефон
- Разрешите установку из неизвестных источников: *Настройки → Приложения → Разрешения → Установка неизвестных приложений*
- Установите APK
- Долгое нажатие на рабочем столе → Виджеты → **Dual Clock Widget**

## Размер виджета
Рекомендуемый размер: **4×1** ячейки (как на скриншоте).
